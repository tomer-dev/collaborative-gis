How we worked

As the process log (docs/process-log.md) records it; the lane table is counted from the tickets on this page.

Lanes

Each epic had a lane label. In M1 and M2 the lanes ran in parallel, each in its own git worktree, with one pull request per task, stacked while a parent pull request was still open, and an integration lane per milestone joined them. After the first deploy the work ran the same way, with one code review per pull request.
